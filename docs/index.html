What & Why

它解决什么

做独立产品最痛的不是「做不出来」，而是「不知道做什么值得做」。这个插件把一次性的调研固化成一套系统：有统一 SOP、有证据可回溯、有评分可比较，还有一条从「发现」到「已验证 / 放弃」的状态流水线。

📡

多平台发现

V2EX、Hacker News、Indie Hackers 等社群，按高讨论帖 → 详情页 → 回复逐条采集，每条信号留原始 URL。

🎯

五维评估

需求证据 / 竞争空间 / 技术可行性 / 变现潜力 / 一人可做性，1–5 分打分，综合分自动求和排序。

📒

跨期台账

所有期的候选汇总成一张可筛选、排序、搜索的商机库。同一方向跨期复用同一 id，横向比较它几个月后还成不成立。

The Closed Loop

闭环：从发现到回填，四步走

插件固化的是流程，不是抓取能力——实际采集由 Agent 用 web_search / web_fetch 完成，不内置爬虫、不自动发帖，关键判断始终由你拍板。

  1. 跑一次调研

    在对话框贴入面板复制的「定制调研指令」，Agent 按 SOP 采集多平台痛点、逐条留 URL、声明未覆盖平台。

  2. 产出并归档

    生成报告 Markdown + 单文件网页 + 结构化 meta.json，放进 reports/<日期-主题>/ 后运行构建脚本。

  3. 进商机库跟进

    候选自动汇总成卡片墙，按状态流转：发现 → 打分 → 排期 → 跟进 → 已验证 / 放弃。状态存本地，刷新不丢。

  4. 回填结果

    验证后回填结论。同一商机跨期复用同一 id，商机库就会把历期数据并排展示，形成会复利的判断资产。

商机库看板

跨所有期聚合的卡片墙：按状态 / 平台 / 评分筛选排序，全文搜索理由与证据。

详情抽屉

点开任一商机，看产品形态、为什么可行、主要风险、五维评分，以及每条证据的原始 URL。

期数报告

按期查看完整报告网页、候选商机、以及可编辑的调研主题 / 平台 / 关键词。

Scoring

五维评分，让「值不值得做」可比

每个候选按 1–5 分打分，综合分满分 25。分数不是结论，是排序与讨论的起点——先访谈、先人工交付、再谈做不做。

需求证据有多少独立、具体的求助信号，回复是否给出具体解法。
竞争空间现有替代品有多弱或多空；是否无直接竞品。
技术可行性一人能否一两周做出可用 MVP。
变现潜力付费方是否明确，痛点是否直接挂钩省钱或赚钱。
一人可做性是否纯软件、无需线下履约、重资产或强牌照。
Getting Started

安装

通过 DeepSeek Harness 的插件管理器一键安装，或用命令行直接把本仓库加入你的 profile。

# 方式一：CLI 从本仓库安装（link 本地目录） dsh plugin --profile desktop add <本仓库路径> # 方式二：直接指向工作区目录安装 # 在插件管理器里 install_bundle → target 指向仓库绝对路径 # 安装/更新后：重启 DSH 应用 → 刷新 Web 页面 # 侧边栏出现雷达图标 → 点开即「介绍」首页

首次安装或更新 client 代码后必须重启应用 + 刷新页面：Host 插件行只在启动时合成。

依赖

DeepSeek Harness 0.2.2 及以上。插件依赖 Harness 已配置的模型与账号，普通阅读不需要额外密钥。

数据在哪

全部本地：reports/ 归档、状态存浏览器 localStorage。无云服务、无遥测、不自动发帖。
